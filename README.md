# systeme-segmentation-chaine-approvisionnement
Système de segmentation double de la chaîne d'approvisionnement : clustering K-means pour classifier les fournisseurs et les clients. Analyse comparative avant/après pandémie (2015-2018 vs 2019-2023), avec étude des effets modérateurs de la transformation digitale et de la chaîne verte. Développé sous R + Power BI.
